Audio Transcription Web App

Transcribe your audio files effortlessly

Welcome to the official GitHub repository for the Audio Transcription Web App! This application allows you to upload audio files and transcribe them using the Vosk speech recognition model. Designed to support multiple languages, it offers an easy-to-use web interface for accurate transcription.

Explore the repository to find the source code, installation instructions, and contribution guidelines. Join our community and enhance your audio transcription experience!
